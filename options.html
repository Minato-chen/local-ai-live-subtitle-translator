Netflix 实时中文字幕

选择轻量快速翻译，或使用带上下文的本机 AI 高质量翻译。

实时优先可用 qwen3:1.7b；专用翻译可用 Hy-MT2 1.8B；质量优先可用 qwen3:4b-instruct。

自动识别语言可将源语言设为 auto。Hy-MT2 模型名为 maternion/hy-mt2:1.8b。

本机启动 LibreTranslate

docker start netflix-translator

本机启动 Ollama

ollama pull qwen3:4b-instruct

Ollama 应用运行时会在本机 11434 端口提供接口，不需要 Docker。
